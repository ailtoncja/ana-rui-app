# Ana Rui: versões do app

Este repositório guarda só as versões do app Android **Ana Rui** (handebol feminino da CAAP UFABC), em
[Releases](https://github.com/ailtoncja/ana-rui-app/releases). O próprio app confere aqui se saiu versão nova e se
atualiza sozinho. O código do projeto fica em outro repositório, privado.

Cada versão tem o APK e um `versao.json` (número da versão, endereço e SHA-256 do APK). O app só instala um APK deste
repositório, com o SHA-256 conferido e assinado com a mesma chave do app instalado.

Para instalar pela primeira vez: baixe o `AnaRui-<versão>.apk` da versão mais recente em Releases.
